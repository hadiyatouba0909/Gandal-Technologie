## À propos

Gandal-Technologie est une jeune entreprise fondée par **Hadiyatou BA** et **Ibrahima Sory Diallo**, deux développeurs full stack passionnés par la transformation digitale en Afrique. Le nom *Gandal* signifie « savoir » en peulh.

Nous concevons des **sites vitrines**, **applications web** et **applications mobiles** performantes, pensées pour l'humain et orientées vers l'impact.

## Stack technique

| Catégorie | Technologies |
|-----------|-------------|
| **Frontend** | React 18, TypeScript, Tailwind CSS |
| **Build** | Vite 5 |
| **Icônes** | Lucide React |
| **Déploiement** | Vercel |

## Démarrage rapide

```bash
# Cloner le projet
git clone https://github.com/hadiyatouba0909/Gandal-Technologie.git
cd Gandal-Technologie

# Installer les dépendances
npm install

# Lancer en développement
npm run dev
```

Le site sera disponible sur `http://localhost:5173`.

## Scripts

| Commande | Description |
|----------|-------------|
| `npm run dev` | Serveur de développement |
| `npm run build` | Build de production |
| `npm run preview` | Prévisualiser le build |
| `npm run lint` | Vérifier le code avec ESLint |

## Déploiement

Le site se déploie automatiquement sur **Vercel** à chaque push sur `main`.

Pour connecter le projet :
1. Aller sur [vercel.com](https://vercel.com) et se connecter avec GitHub
2. Cliquer **Add New Project** et importer `Gandal-Technologie`
3. Vercel détecte automatiquement Vite — cliquer **Deploy**
